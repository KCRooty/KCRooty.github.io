Arranca Static Linux

Primer paso de la distribución de Static Forge: base Arch, detección de hardware y un XFCE con tema propio.

Static Linux nace con una idea: un Arch que funciona nada más instalarlo, con buen aspecto y sin pelearse con él.

  • sl-detect: mira el hardware (gráfica, RAM, firmware, disco) y recomienda el entorno, el sistema de archivos y el kernel que mejor le van a esa máquina.
  • XFCE con tema: el primer escritorio, con la marca del estudio.
  • Diez acentos de color para elegir.

Static Linux starts with one idea: an Arch that works right after install, looks good and doesn't fight you.

  • sl-detect: looks at the hardware (GPU, RAM, firmware, disk) and recommends the environment, filesystem and kernel that suit that machine best.
