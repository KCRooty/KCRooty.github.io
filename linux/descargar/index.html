Descarga Static Linux

Una ISO de 64 bits (x86_64, UEFI) que arranca directamente en el instalador. El escritorio, el tema, los sabores y el perfil de privacidad se eligen al instalar, y se instala con conexión o sin ella.

Versión de prueba 2026.11.14. static-linux-2026.11.14-x86_64.iso, 4,8 GB. Se instala de principio a fin en máquinas virtuales, con red o sin ella, pero aún no se ha probado en hardware real desde la ISO. Pruébala en una máquina virtual o en un disco que no necesites. Los problemas conocidos están en la nota de la versión.

Solo x86 de 64 bits, con UEFI. Secure Boot tiene que ir apagado (GRUB va sin firmar). El arranque en BIOS antigua está por probar. Para instalar no hace falta conexión; los sabores (Gaming, Oficina…) se añaden cuando la tengas.

03 · verificar

Comprueba la ISO

Cada ISO lleva su suma SHA256 y una firma hecha con la clave de Static Forge. Con los archivos en la misma carpeta:

sha256sum -c static-linux-2026.11.14-x86_64.iso.sha256
# la clave, una vez
curl -O https://staticforge.me/linux/static-forge-release.asc
gpg --import static-forge-release.asc
gpg --verify static-linux-2026.11.14-x86_64.iso.sig

La huella de la clave es 3E61 7ED0 6C90 C757 35C9 C45E 51D5 8FA3 5045 B8D0. Es la misma que firma el repositorio de paquetes de Static Linux.

SHA256: 6b34906f4745ff577b1730701c987f9e862ed80954c8655c81850fb8d17aa302

04 · construir

Construye la ISO

En Arch o Static Linux, con unos 25 GB libres. El script construye los paquetes propios y después la ISO con archiso.

# herramientas
sudo pacman -S --needed archiso git base-devel
# código
git clone https://github.com/KCRooty/static-linux
cd static-linux
# paquetes propios, como usuario normal
packages/local-repo.sh
# ISO universal (~4,8 GB, sale en iso/out/)
sudo iso/build.sh universal

Detalles y opciones en iso/README.md del repositorio. Para probarla sin tocar tu disco, arráncala en QEMU o VirtualBox con UEFI activado.

05 · actualizaciones

Continua, como Arch

Una vez instalada no hay que reinstalar para tener versiones nuevas: el sistema se actualiza entero. Las ISO nuevas solo acortan la primera instalación.

sudo pacman -Syu   # o: paru
