Descarga Static Linux

Una ISO de 64 bits (x86_64, UEFI) que arranca directamente en el instalador. El escritorio, el tema, el estilo, los sabores y el perfil de privacidad se eligen al instalar.

Todavía no hay ISO pública. La última del taller es static-linux-2026.11.13-x86_64.iso y se instala de principio a fin en una máquina virtual, pero aún necesita red para instalar y solo se ha probado entera con XFCE. Se publicará firmada cuando esté lista para usarse fuera del taller, y se anunciará en el blog.

Solo x86 de 64 bits, con UEFI. Secure Boot tiene que ir apagado (GRUB va sin firmar). El arranque en BIOS antigua está por probar. Por ahora el instalador necesita conexión a internet.

03 · construir

Construye la ISO

En Arch o Static Linux, con unos 15 GB libres. El script construye los paquetes propios y después la ISO con archiso.

# herramientas
sudo pacman -S --needed archiso git base-devel
# código
git clone https://github.com/KCRooty/static-linux
cd static-linux
# paquetes propios, como usuario normal
packages/local-repo.sh
# ISO online (~1,7 GB, sale en iso/out/)
sudo iso/build.sh online

Detalles y opciones en iso/README.md del repositorio. Para probarla sin tocar tu disco, arráncala en QEMU o VirtualBox con UEFI activado.

04 · verificar

Comprueba la ISO

Cuando salga la ISO pública, cada una llevará su suma SHA256 y su firma GPG. Con los tres archivos en la misma carpeta:

sha256sum -c static-linux-VERSION-x86_64.iso.sha256
gpg --verify static-linux-VERSION-x86_64.iso.sig

La clave de firma se publicará aquí y en el repositorio junto con la primera versión.

05 · actualizaciones

Continua, como Arch

Una vez instalada no hay que reinstalar para tener versiones nuevas: el sistema se actualiza entero. Las ISO nuevas solo acortan la primera instalación.

sudo pacman -Syu   # o: paru
