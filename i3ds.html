CH 09 · MOTOR 3D OPEN SOURCE

Iron3D Studio

Un DCC 3D construido desde cero en C++/Vulkan que recrea el flujo de trabajo de Cinema 4D R19 — Gestor de Objetos, cámara orbital, grafo de escena — código 100% propio, reimplementación clean-room.

Ver el repositorio Ver el progreso

01 · QUÉ ES

Un DCC clásico, reconstruido

MOTOR

Evaluación en GPU, no en un solo núcleo

Vulkan 1.3 como API gráfica, VMA para la gestión de memoria y Dear ImGui sobre Vulkan para la interfaz. Windows y Linux con paridad total, sin excepciones.

FLUJO DE TRABAJO

Familiar, si conoces C4D

Cámara orbital con Alt+clic como Cinema 4D, un Gestor de Objetos real con jerarquía y selección, y compatibilidad planeada con archivos .c4d/.lib4d y plugins de R19 (siempre traducidos de Python 2 a Python 3).

03 · CLEAN-ROOM

Ni una línea de código de Maxon

Iron3D Studio solo observa Cinema 4D R19 desde fuera — entrada y salida, comportamiento — el mismo modelo que usan Wine, ReactOS o LibreOffice. Nunca se copia, lee ni decompila código, shader, preset o asset de Maxon para escribir el código de Iron3D. Las reglas completas viven en el archivo AGENTS.md del repositorio.

Ver el repositorio Ver otros proyectos

Iron3D Studio no tiene relación oficial con Maxon ni con Cinema 4D. Es una reimplementación independiente y clean-room de Static Forge.
